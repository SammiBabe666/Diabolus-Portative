# Installer

`Diabolus-Portative-installer.html` is the Open-XY browser builder with
Diabolus Portative inside. Save it, open it in Chrome, Edge or Opera, and
follow [INSTALL.md](../INSTALL.md). It reads the OS from your own OP-XY and
gives you the files to copy. No firmware is included in this repository.

Made with `sdk.py kit --personal` from SDK commit 892ad936 and machine commit 0768148
(the machine code is unchanged since).
